# CODEX_TASK_PROTOCOL.md

## Default operating mode

Use targeted MVP-style patches.

Before editing:

1. Read `AGENTS.md`.
2. Read `docs/CODEX_PROJECT_STATE.md`.
3. Touch only files named in the task.
4. Do not search the whole repo unless necessary.

## Patch discipline

- Minimal changes.
- No broad refactors.
- No unrelated formatting.
- No Docker unless requested.
- No long reports unless requested.
- No legacy endpoint removal unless requested.

## If uncertain

Do not guess. Add a warning or ask.
